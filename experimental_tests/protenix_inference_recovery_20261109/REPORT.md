## 已落实的修复

1. **恢复 PPU 原有的高效注意力入口。** 合并后的注册替换使部分调用进入另一套注意力实现。恢复原有 PPU 原生 efficient attention 入口，同时保留 FlagGems 的 MM、BMM 和三角注意力优化。
2. **减少算子外层的重复工作。** MM 先按已有适用条件排除不需要候选分支的调用；简化内核缓存键生成；乘法按实际执行分支再准备广播和步长信息。
3. **减少完整写入输出的分配开销。** 新增可选的 C++ 分配入口，调用 PyTorch 原有 CUDA 内存分配器。逐元素算子、直接 MM 和 BMM 的输出由计算内核完整写入，省去输出使用前的冗余初始化和多次 Python 分配调用。计算内核和累加顺序保持原样。

前两项进入本轮 111 组验收。第三项使用独立的同卡对照测试，见下一节。所有新旧源码、编译产物摘要和实际加载路径均随实验保存。
